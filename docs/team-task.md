Project Team Responsibilities

Project Coordination

- Maintain project goals, milestones, and GitHub documentation.
- Review progress and coordinate integration across team members.

Hardware and Embedded Systems

- Verify component specifications and prepare wiring documentation.
- Implement sensor interfaces, motor control, and firmware integration.

Software and Testing

- Develop control logic and unit tests.
- Maintain test procedures, record actual results, and document bugs.

Integration and Demonstration

- Integrate verified hardware and software components.
- Record demonstrations, testing conditions, limitations, and final results.

Progress Reporting

Each member should update their assigned tasks, relevant commits, blockers, and next steps during project reviews.

Actual responsibilities should be assigned according to each member's availability and skills.
